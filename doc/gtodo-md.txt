1. 概要                                                 *gtodo-md-introduction*

|gtodo-md.nvim| は、Neovim 内で Markdown ファイルを用いて GTD（Getting Things
Done）の軽量版を実現するためのTodo管理プラグインです。

以下のファイルが自動的に生成・管理されます：
- inbox.md      : 未整理のタスクを追加する場所
- todo.md       : Today, Next, Waiting, Someday のセクションに分類されたタスク
- done.md       : 完了したタスクの履歴（月別に自動ソート・アーカイブ）
- cancelled.md  : キャンセルされたタスクの履歴

2. 設定方法                                            *gtodo-md-configuration*

プラグインマネージャー経由でインストール後、以下のセットアップを呼び出します。
デフォルト設定値は以下の通りです：

>lua
    require("gtodo-md").setup({
      -- タスクファイルの保存先ディレクトリ
      data_dir = vim.fn.stdpath("data") .. "/gtodo-md",

      -- デフォルトのキーバインドを有効化するかどうか
      use_default_keymaps = true,

      -- タスク検索時のファジーファインダー指定 ("auto" | "snacks" | "telescope" | "fzf-lua" | "builtin")
      picker = "auto",

      -- デフォルトキーマップの接頭辞（プレフィックス）
      keymap_prefix = "<Leader>t",

      -- 期限切れ警告通知の最小間隔（秒）。デフォルト30分
      due_notification_cooldown = 1800,

      -- Neovim終了後も通知制限の時間をディスクに保存して維持するかどうか
      due_notification_persist = true,
    })
<

3. コマンド                                                 *gtodo-md-commands*

提供されているユーザーコマンド一覧です：

:GtodoTodo
        `todo.md` をフローティング表示で開きます。

:GtodoInbox
        `inbox.md` をフローティング表示で開きます。

:GtodoDone
        `done.md` (完了履歴) をフローティング表示で開きます。

:GtodoCancelled
        `cancelled.md` (キャンセル履歴) をフローティング表示で開きます。

:GtodoSort
        `todo.md` 内のタスクを手動で期日順にソートします。

:GtodoSearch
        タグ（+）やコンテキスト（@）、未完了・完了の条件でAND絞り込み検索を
        実行します。

4. キーマップ                                                *gtodo-md-mappings*

`use_default_keymaps = true` の場合のデフォルトキーバインドです。
(以下はプレフィックスが `<Leader>t` の場合の例)

グローバルキーマップ (すべてのバッファで有効):
キー            動作
------------------------------------------------------------------------------
<Leader>tt      `todo.md` をフローティング表示で開く
<Leader>ti      `inbox.md` をフローティング表示で開く
<Leader>thd     `done.md` (完了履歴) をフローティング表示で開く
<Leader>thc     `cancelled.md` (キャンセル履歴) をフローティング表示で開く
<Leader>ta      タスクの追加または編集 (タスク行で押すと編集、それ以外は新規追加)
<Leader>t/      タスクのAND絞り込み検索の実行

バッファローカルキーマップ (`todo.md` / `inbox.md` バッファ内でのみ有効):
キー            動作
------------------------------------------------------------------------------
<Leader>td      カーソル行のタスクを `Today` セクションへ移動
<Leader>tn      カーソル行のタスクを `Next` セクションへ移動
<Leader>tw      カーソル行のタスクを `Waiting` セクションへ移動
<Leader>ts      カーソル行のタスクを `Someday` セクションへ移動
<Leader>tx      タスクの完了状態をトグル (完了時に `completed_at` を付与)
<Leader>tc      タスクをキャンセルし、`cancelled.md` へ移動
<Leader>tjp     カーソルの `+プロジェクト名` から対応するプロジェクトファイルへ
                ジャンプ (存在しない場合はテンプレートから自動作成)
<Leader>to      手動で期日チェックおよび自動ソートを実行
